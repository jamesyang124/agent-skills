# Flow internals and expression pitfalls (Power Automate / Logic Apps)

Generated by `scripts/gen_flow_definition.py`. ~220 actions; everything is deterministic from the template export.

## Connector parameter keys (verified to import)
| Operation (`operationId`) | parameters |
|---|---|
| `PostCardToConversation` | `poster`="Flow bot", `location`="Channel", `body/recipient/groupId`, `body/recipient/channelId`, `body/messageBody` (string(card)) |
| `UpdateCardInConversation` | same + `body/messageId` |
| `ReplyWithMessageToConversation` | same as Post + `body/parentMessageId` (HTML `body/messageBody`) |
| `ReplyWithCardToConversation` | same as Reply message |
| `GetMessagesFromChannel` | `groupId`, `channelId` → `body.value[]` (Flow-bot card JSON is in `attachments[].content`, not `body.content`) |

## Pitfalls hit while building
- Build the card as a **Compose object**, then `string(outputs('…'))`. Interpolating into a JSON string breaks on quotes/newlines in PR titles or comments.
- Newlines: use `decodeUriComponent('%0A')`; `'\n'` inside an expression is not a newline. Strip `%0D` first.
- `isVisible` accepts a pure expression (`"@not(equals(…))"` returns a boolean) → conditional elements without separate cards.
- Do not put dynamic text that can contain `<` into the HTML reply without escaping (`replace(replace(x,'<','&lt;'),'>','&gt;')`).
- Read-back of previous state: `json(first(root)['attachments'][0]['content'])` then `Query` on `body` where `id == 'p_activity'`, etc. Hidden TextBlocks must be top-level (not inside a ColumnSet).
- Action names must be unique across the whole workflow; prefix per branch (`Cre_`, `UpdR_`, `CmtR_`, `Late_`).
- `min(a,b,…)`, `take`, `skip`, `union`, `join`, `last`, `split`, `trim`, `indexOf` (case-insensitive), `convertTimeZone` (Windows tz names, e.g. `Taipei Standard Time`) are all available.
- ADO `message.text` examples: `X approved pull request N (title)`, `X completed pull request N (title)`. Name = text before the earliest verb marker.
- Trigger schema must accept arbitrary JSON, otherwise ADO payloads are rejected.
- A template flow's default action posts `string(variables('Body'))` as the card → HTTP 202 but the run fails (`Property 'type' must be 'AdaptiveCard'`). This is expected until the merged definition is imported.
